# 阅读设置

## 移动端来源与作者

宽度小于 768px 时，单个订阅源的文章列表也显示“订阅源名称 + 人物图标 + 作者”。列表和卡片、未读和收藏筛选使用同一规则，改变窗口宽度会立即切换展示。

两名称相同或互相包含时只显示订阅源名称；比较去掉两端空白并忽略英文大小写。没有作者时显示订阅源名称。文章详情只要有作者，就始终显示订阅源名称和作者。

## 已读文章保留上限

在“系统设置 → 阅读 → 每个订阅源已读保留上限”输入正整数并点击保存，默认 **1000**。仅限制已读、未收藏文章；未读和收藏不计入上限，也不会被清理。

每个订阅源独立保留最新 N 条符合条件的文章，按发布时间倒序；时间相同时优先保留较新的文章 ID。保存后立即清理超出部分，并在启动时及每 24 小时清理。两次清理之间可能暂时超过上限。

提高上限不会主动恢复已经删除的历史文章。清理失败会记录日志并在下一轮重试。此设置保存在 SQLite 中，随完整数据库备份保存。

现有受访问认证保护的 `GET /api/settings` 返回 `read_items_keep_limit`；`PUT /api/settings` 可以更新：

```json
{"read_items_keep_limit": 1000}
```

仅接受 1～9007199254740991 的整数；0 不代表无限保留。空值、负数、小数、字符串和其他非法值返回 HTTP 400，不修改设置。缺失或异常的历史配置使用默认值 1000。
